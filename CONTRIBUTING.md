# Contributing

Bug reports, careful review, testing and focused patches are welcome. This project is AI-assisted; disclose any AI assistance in your contribution. You remain responsible for understanding, testing and having the right to submit the change. Do not forward this project's patches to upstream projects without following their own contribution policies; some reject AI-generated contributions.

For a suggested commit, first describe the problem in a Feature or patch proposal issue. A pull request should explain the trigger and resulting behavior, link its issue, describe relevant tests, and state what remains unverified. Keep unrelated changes separate. Commit messages should say what changed and why.

Do not commit ROMs, extracted game content, generated RecompiledFuncs output, personal saves, passwords/tokens, runtime logs with private data, or tool/build binaries. Use the pinned dependency setup rather than substituting a different upstream branch. Preserve copyright and license notices. New artwork or audio needs recorded provenance and permission.

Source changes you contribute must be compatible with the applicable project/dependency license. Proposing a patch does not transfer ownership of upstream work to this maintainer. Do not claim that an offline test proves visual correctness or that multiplayer is stable without reproducible live evidence.

For performance/rendering problems, record map, mode, camera direction, settings and a short reproduction. For multiplayer, record host/client roles, player count, game type, connection result and which machine failed. Never post your ROM to help reproduce a bug.
