More Characters 2.0.5 - native rider skins (experimental)

Requires the Native Skins 01 private candidate or a later compatible build.
The public 1.4.2 release does not include this texture-only skin loader.

Install the separate .nrm file through the Mods tab and enable More Characters
before starting the game. Cycle past the last original rider to select a skin.
The original character roster remains available. Local players choose separately.
Restart the application after installing or changing the pack.

These skins use the game's original male or female model, posture, animation and
physics, with newly authored low-resolution texture artwork. Cortana uses the
female model. No replacement high-poly geometry is included.
Ghost Rider's flames are painted texture detail in this version.

Version 2.0.1 corrects the human head artwork for the native mirrored half-face
layout, including matching detail at a distance. The game executable, original
models, animation and gameplay are unchanged from Native Skins 01.

Version 2.0.2 extends Marcus's black bandanna over the full crown and adjusts
Link's facial spacing on the native head. These are texture and packing changes.

Version 2.0.3 repairs the center of Link's face texture so the native mirrored
halves join without the old profile outline. Other appearances are unchanged.

Version 2.0.4 aligns the body clothing panels for Doom Guy, Vin Diesel, Link,
Marcus Fenix, Riddick, Dominic Santiago and Green Pants Rider. It also corrects
selected arm and trouser material patches at different viewing distances.
The corrected faces, original riding poses and the other four skins are retained.

Version 2.0.5 replaces Doom Guy's helmet with a short-haired, unhelmeted face
based on the supplied character reference. His body colors and all ten other
skins remain unchanged.

Your own supported Road Rash 64 ROM supplies the native models and animation.
This archive contains only authored texture payloads and mod metadata: no ROM,
extracted model, original texture, native asset header or save file.
Online skin synchronization is not included in this experimental mod.

Replace the retired More Characters mesh prototype if it is still installed;
do not install two packs with the same mod identity. The optional HD texture
mod can remain installed separately.

Fan-made interpretations; character names belong to their respective owners.
Artwork was created with built-in image generation and adapted to native UV
layouts. Pillow performs offline palette conversion; no new runtime dependency.
