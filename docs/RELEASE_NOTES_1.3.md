# Road Rash 64 Recompiled 1.3

- **Online (experimental):** host-authoritative gameplay, individual rider/bike selection, readiness indicators, disconnect handling and proximity voice with microphone settings. Sync and jitter issues may remain.
- **Split screen:** improved HUD/countdown placement and corrected pickup positioning.
- **Custom Cop:** optional AI cops, refined bust/victory handling, clearer selection prompts and corrected attack controls.
- **Gameplay and controls:** simpler input setup, player eject fixes, corrected backtracking distance readings and recovery near the crash location.
- **Presentation and maintenance:** removed the distracting cloud layer, retired unused sky experiments, and improved code organization and contributor notes.

**Draw Distance:** maximum can load the entire map, including all race areas. Looking toward dense distant geometry can reduce performance, especially in split screen. **50-60% is the recommended sweet spot.**

Windows is user-tested. Linux is a separate experimental download; this integrated version has not been gameplay-tested on Linux. Online remains experimental on both platforms. Bring your own supported Road Rash 64 USA v1.0 ROM; no ROM or soundtrack is included.
