# Road Rash 64 Recompiled 1.3.1 Hotfix

- **Controller compatibility:** added known 8BitDo 64 mappings and fixed a button-remapping cancellation bug. Automated input checks passed; the actual controller remains untested, so this is a potential compatibility fix pending hardware confirmation. Controls layout and saved bindings are unchanged.
- **Optional texture mod:** restored Crisaty (Cristian A.T.)’s Remastered Edition RT64 texture conversion, omitted from 1.3. Install the included `optional-mods` RTZ through Settings > Mods.

The Windows package passed the release owner's general gameplay test. Players must provide their own supported Road Rash 64 USA v1.0 ROM; no ROM or soundtrack is included. The optional mod supplies replacement textures.

Online multiplayer remains experimental. Draw Distance can load the entire map across all race areas; dense geometry can reduce performance, especially in split screen. **50–60% is the recommended starting point.**

This hotfix provides a Windows download and updated source. The experimental Linux binary remains available in [1.3](https://github.com/linkssy2/RoadRash64Recompiled/releases/tag/v1.3.0); it does not include this hotfix.
