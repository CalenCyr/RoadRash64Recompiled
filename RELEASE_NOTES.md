# Road Rash 64 Recompiled 1.3.1 Hotfix — Revision 2

- Improved 8BitDo 64 Bluetooth controller support in Switch mode, including C-button remapping. The Linux reporter confirmed the other buttons can be configured; L3 remains unavailable through their Linux N64 driver path. D-mode support is retained. Controls layout and saved bindings are unchanged; affected buttons may need remapping.
- Includes the optional Remastered Edition texture mod by Crisaty (Cristian A.T.). Install its RTZ through Settings > Mods.

Separate Windows and experimental Linux downloads are provided. Windows passed 87 offline controller checks; Linux passed 161. Controller hardware confirmation is Linux-only; L3 support is not claimed for that tested driver. No new Windows gameplay test was performed for this revision.

Linux requires x86-64, Vulkan drivers, an audio server, GLIBC 2.35+ and GLIBCXX 3.4.30+. Some Linux desktop integrations may report GLib/GIO module warnings; their compatibility remains under investigation.

Your own supported Road Rash 64 USA v1.0 ROM is required. No ROM or soundtrack is included. The optional mod supplies replacement textures.

Online multiplayer remains experimental. Draw Distance can load the entire map across all race areas. Dense distant geometry can slow the game, particularly in split screen; 50–60% is the recommended starting point.
